Either the installer from python.org/downloads, or winget in a terminal.

Either the installer from python.org/downloads, or Homebrew (brew.sh) in a terminal.

A name refers to a value. = binds it.

An f-string puts values inside text: f"...{expression}...".

Names and what they refer to are the subject of a whole lecture: binding and scope.

Types you can write down


a: int = 3
c: str = "Hello"

def add(x: int, y: int) -> int:
    return x + y

print(add(2, 3))         # 5
print(add("2", "3"))     # 23 -- Python does not stop you

Annotations say what a name should hold.

Python does not check them while running. VS Code underlines the second call in red; mypy file.py reports it from the terminal.

A type is a claim about a program that can be checked without running it.

Recursion


def factorial(n: int) -> int:
    if n == 0:
        return 1
    return n * factorial(n - 1)

def total(xs: list[int]) -> int:
    if not xs:
        return 0
    return xs[0] + total(xs[1:])

factorial(5)        # 120
total([1, 2, 3])    # 6

A function that calls itself on a smaller piece of the problem.

Every interpreter in this course is a recursive function: one call per piece of the program.

Functions are values


from collections.abc import Callable
import operator

def twice(f: Callable[[int], int], x: int) -> int:
    return f(f(x))

twice(lambda n: n + 3, 10)     # 16

def adder(k: int) -> Callable[[int], int]:
    return lambda n: n + k     # a function, returned

adder(3)(10)                   # 13

ops: dict[str, Callable[[int, int], int]] = {
    "+": operator.add,
    "*": operator.mul,
}
ops["*"](6, 7)                 # 42

A function can be passed, returned, and stored in a dictionary.

lambda writes a small one without a name. Callable[[int], int] is its type: takes an int, gives an int.

Data classes: a tree in a few lines


from dataclasses import dataclass

@dataclass(frozen=True)
class Num:
    value: int

@dataclass(frozen=True)
class Add:
    left: "Expr"
    right: "Expr"

Expr = Num | Add

e = Add(Num(2), Add(Num(3), Num(4)))    # 2 + (3 + 4)

@dataclass writes the boring parts of a class for you: constructor, printing, equality.

frozen=True: once built, it cannot change.

This is how the course writes the syntax of a language: one class per kind of node.

match: one case per kind of node


def evaluate(e: Expr) -> int:
    match e:
        case Num(v):
            return v
        case Add(l, r):
            return evaluate(l) + evaluate(r)

evaluate(Add(Num(2), Add(Num(3), Num(4))))   # 9

match looks at the shape of a value and takes it apart.

case Add(l, r): if e is an Add, call its two children l and r.

Data classes plus match plus recursion: that is an interpreter. Lecture 2 is all about it.

Reading and writing a file


with open("notes.txt", "w") as f:
    f.write("first line\n")
    f.write("second line\n")

with open("notes.txt") as f:
    for number, line in enumerate(f, start=1):
        print(number, line.strip())

open gives a file; with closes it when the block ends, even after an error.

Your programs will read other programs from files: this is how.

When things go wrong


def safe_divide(a: float, b: float) -> float | None:
    try:
        return a / b
    except ZeroDivisionError:
        print("division by zero")
        return None

safe_divide(1, 0)      # prints, returns None

An error is an exception: it stops the program unless someone catches it.

Each has a name: opening a missing file raises FileNotFoundError, int("x") raises ValueError. Raise one yourself with raise ValueError("expected a number").

What 1 / 0 means is a decision. Python raises; you will decide for your own language.

A program in a file


# calc.py
from dataclasses import dataclass   # standard library
from lark import Lark               # installed with pip

def main() -> None:
    print("calc is running")

if __name__ == "__main__":
    main()

import takes code from elsewhere: Python's own library, a package installed with pip, or another file of yours.

The last two lines run main when the file is run, not when another file imports it.
